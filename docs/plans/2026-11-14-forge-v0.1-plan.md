# forge v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (native, inline — user rule: no subagents). While writing skill files also load `mattpocock-skills:writing-for-agents` + `superpowers:writing-skills`. Steps use `- [ ]` checkboxes.

**Goal:** Ship `forge` v0.1.0 — one Claude Code skill, packaged as plugin in `forge-kit` repo, covering onboard, ai-readiness, design, architect, impl-plan, develop, test, review.

**Architecture:** Router `SKILL.md` (<150 lines) holds routing, docs-root resolution, sizing, resume. Everything else is disclosed reference loaded per branch: `rules/` (single source of truth), `stages/`, `domains/`, `templates/`. Verified by a structural check script + dogfooding on Leadly in fresh sessions.

**Tech Stack:** Markdown, JSON manifests, bash check script. No runtime code.

**Spec:** `docs/specs/2026-11-14-forge-design.md` (v2). Section refs below = spec §.

## Global Constraints

- Repo root: `~/Documents/icloud-archive-folder-back-up/Documents/Projects/18_Agent_Skills/repos/forge-kit`
- No `git commit` / `git add` / `git push` by the agent. `git init` allowed. Each task ends with "hand back diff summary".
- `SKILL.md` < 150 lines. Each rule stated once (in `rules/`); stages point to it, never restate.
- Doc style everywhere: concise, skip grammar, tables/bullets, code over prose (spec §10 doc-style).
- Default docs root `docs/forge/`; override `forge-docs: <path>` line in project `CLAUDE.md` (§7).
- Naming: task folder `NN_<kebab-slug>`; design `YYYY-MM-DD_<slug>_design.md`; impl step `NN_<kebab-slug>.md`; review `YYYY-MM-DD_<type>_review.md` (§7).
- Ledger statuses exactly: `⬜ not started` · `🔄 in progress` · `✅ done` · `⛔ blocked` (§8).
- Guardrails exactly as spec §10 list 1–9.
- License MIT. Plugin name `forge`, marketplace name `forge-kit`, version `0.1.0`.

## Review Focus

1. **No CLAUDE.md, no `docs/forge/`** → forge asks root once, offers to add `forge-docs:` line; never silently writes elsewhere. → Task 4 check + Task 5 dogfood A.
2. **Multiple in-progress tasks** → `/forge` lists from `tasks/index.md` and asks; never guesses. → Task 4 check + Task 7 dogfood.
3. **Task numbering** → next number = max existing `NN` + 1, never reused even after deletion. → Task 4 SKILL.md rule + Task 6 dogfood (create 2 tasks).
4. **Ledger `✅ done` without `Verified by`** → develop refuses to mark done; review flags it. → Task 3 template + Task 7 stage rule.
5. **`forge-docs:` with `~` or path outside repo, dir missing** → expand `~`, confirm before creating dir. → Task 4 SKILL.md rule + Task 5 dogfood B.
